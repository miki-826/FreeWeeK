いいね。
このゲームは **「平日5日を突破して土日に自由を取り戻す」** という体験なので、UIは単なるタスク画面よりも、**1日が終わった感・退勤した感・夜になった感** を強めるとかなりゲームっぽくなります。

添付の要件では、月〜金の5日間で30秒タスクをこなし、自由ゲージを貯めて土日解放エンディングに進む構成になっているので、UIもそこに合わせるのが良いです。

# UIコンセプト

## タイトル案

**「自由まで、あと5日。」**

または

**「退勤勇者：土日の自由を取り戻せ」**

平日は仕事風ミニゲーム、土日は報酬という構成なので、
**仕事 × RPG × 退勤演出** が一番合います。

---

# 全体UIの方向性

## 世界観

**平日ステージを1日ずつ攻略して、金曜日の夜に自由が解放されるゲームUI**

雰囲気はこんな感じ。

| 要素     | 表現              |
| ------ | --------------- |
| 月〜金    | ダンジョン / 仕事ステージ  |
| 30秒タスク | 業務クエスト          |
| 採点     | AI上司 / AI審査官の評価 |
| 自由ゲージ  | 土日解放ゲージ         |
| 1日の終了  | 退勤・夕焼け・夜・駅・帰宅   |
| 土日     | 解放された自由エリア      |

**「今週も始まってしまった……でも土日の自由を取り戻すぞ」**

│ ░░░░░░░░░░░░░░░░░░          │

# 3. タスク開始画面

30秒タスクに入る前に、少し演出を入れる。

## 例

```text
火曜日 09:00

AI上司：
「今日の業務クエストを開始します」

MISSION
取引先メールを整えろ

制限時間：30秒

[ START ]
```

### ポイント

いきなり問題を出すより、
**1〜2秒だけミッション演出** を挟むとゲーム感が出ます。

# 「1日が終わったぽさ」を出す具体演出

特におすすめはこれ。

## 1. ボタン文言を変える

普通のUIだと、

```text
[ 次へ ]
```

だけど、このゲームでは、

```text
[ 退勤する ]
[ 帰宅する ]
[ 明日に進む ]
[ 今日を終える ]
```

にする。

これだけで体験がかなり変わります。

---

## 2. 背景を朝→夕方→夜に変える

1ステージの中で背景を変える。

```text
開始：朝
タスク中：昼
結果：夕方
DAY END：夜
```

特にDAY END画面は、
**夕焼けのオフィス街 / 帰り道 / 駅のホーム** が合います。

---

## 3. 時計表示を入れる

```text
09:00 出勤
12:30 業務中
18:45 退勤
21:00 帰宅
```

実際の時間ではなく、ゲーム内時間でOK。

---

## 4. 日報風のリザルトを出す

```text
本日の日報

対応タスク：1件
評価：A
獲得自由：+18%
残業：なし
気力：+5
```

「仕事が終わった感」が出ます。

---

## 5. 最後に一言ナレーション

```text
PCを閉じた。
今日の業務は終わった。
少しだけ、自由に近づいた。
```

これを毎日変えるとかなり良いです。

# MVPで実装するならこのUIがいい

最初から凝りすぎるより、ハッカソンではこの5画面に絞るのが良いです。

| 優先度 | 画面        | 理由           |
| --: | --------- | ------------ |
|   1 | ホーム画面     | 世界観を伝える      |
|   2 | タスク画面     | メイン体験        |
|   3 | 採点結果画面    | AI活用が伝わる     |
|   4 | DAY END画面 | 1日が終わった感を出せる |
|   5 | 土日解放画面    | 最後の気持ちよさ     |

# 最終イメージ

このアプリのUIは、こういう体験にすると強いです。

```text
朝、出勤する
↓
AIが今日の業務クエストを出す
↓
30秒で回答する
↓
AI上司が採点する
↓
仕事モンスターを倒す
↓
自由ゲージが上がる
↓
夕方になる
↓
退勤する
↓
「今日が終わった」と表示
↓
金曜日まで進める
↓
土日が解放される
↓
自由だ！
```

一番大事なのは、
**タスク完了 = 次の問題へ** ではなく、
**タスク完了 = その日が終わる**
にすること。

これだけで、かなりゲーム体験として気持ちよくなります。
